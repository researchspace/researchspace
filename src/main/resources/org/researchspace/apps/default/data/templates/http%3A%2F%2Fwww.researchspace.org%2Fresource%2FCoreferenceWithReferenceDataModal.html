[[!-- "Coreference with reference data" button and dialog for an existing record, the counterpart of rsp:ImportFromExternalSourceModal for records that are already in the system. Expects the same variables in scope: viewId, iri, resourceOntologyClass, resourceName, resourceLabelPattern and collection. The RDS types are preselected from the class of the record where there is an obvious match, and can be changed in the dialog. To preselect datasets as well, set coreferenceDatasets (comma-separated, e.g. "gnd,ulan,wikidata") in the including template; coreferenceTypes overrides the types. The label of the record is looked up around the dialog, not inside it: the content of a dialog is shown by the overlay system and does not inherit the variables of the surrounding template, so everything it needs is passed through the options of the inline-template. --]] [[!-- always one row; ?searchLabel is unbound when the record has no label --]]
