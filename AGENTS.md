# Repository agent instructions

- Add the minimal SPDX license header to every new source-code file, replacing
  `YYYY` with the current year and using the file's comment syntax:

  ```text
  /**
   * Copyright (c) YYYY ResearchSpace contributors.
   *
   * SPDX-License-Identifier: AGPL-3.0-or-later
   */
  ```

- Keep commit messages very brief and limited to one sentence.
- Add code comments only when they explain intent that is not obvious from the
  code itself. Keep those comments brief.
